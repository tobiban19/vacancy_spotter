> **Дата**: 2026-07-28  
> **Статус**: Одобрено пользователем (Approved)  
> **Цель**: Интеграция модуля мониторинга Telegram-каналов с мультитенентным бэкендом, фильтрация вакансий по стоп-словам пользователей и доставка персональных карточек согласования в Telegram-бот.

## 2. Архитектура и Бэкенд Сервисы (`backend/`)

### 2.1 Таблица `user_job_cards` в базе данных
- `id`: INTEGER PRIMARY KEY
- `user_id`: BIGINT (Telegram User ID)
- `raw_text`: TEXT (исходный текст вакансии)
- `channel_title`: VARCHAR(256)
- `author_contact`: VARCHAR(128)
- `status`: VARCHAR(32) (`awaiting_review`, `approved`, `sent`, `skipped`)
- `draft_reply`: TEXT (сгенерированный ИИ-отклик по профилю пользователя)
- `created_at`: TIMESTAMP

### 2.2 Модуль фильтрации вакансий (`backend/matching_service.py`)
1. Проверка `channel_id` в подписках `user_channels`.
2. Проверка стоп-слов пользователя (`stop_words` из профиля).
3. Проверка совпадения профессии и требований к опыту.
4. Вызов ИИ-агента для формирования персонализированного черновика отклика по резюме фрилансера.

### 2.3 Интерактивные кнопки карточки в Bot (`backend/bot_service.py`)
При поступлении новой вакансии бот отправляет сообщение:
```text
🎯 Новая вакансия в канале @editors_video!

📋 Описание: Ищем Reelsmaker на проектный монтаж 10 роликов...
👤 Контакт: @client_username

💬 Черновик отклика:
"Здравствуйте! Я моушн-дизайнер с опытом 3 года..."

[✅ Отправить отклик] [✏️ Изменить]
[⏩ Пропустить]
```

---

## 3. Критерии Проверки (Verification)
1. Поступление вакансии из канала автоматически фильтруется по стоп-словам пользователя (например: при наличии слова "бартер" карточка отклоняется).
2. Для подпадающих пользователей создаётся запись `user_job_cards`.
3. Бот отправляет красивую карточку с inline-кнопками в личный чат пользователя.
4. Нажатие кнопки `[✅ Отправить отклик]` меняет статус в БД на `approved` / `sent`.
